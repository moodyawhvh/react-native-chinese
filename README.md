## 📖 项目简介

React Native 是 Meta 开源并捐赠给 React 基金会的跨平台应用开发框架，让你用 [React](https://react.dev/) 构建真正的原生应用：业务逻辑用 JavaScript 编写，界面由原生代码渲染。秉承"一次学习，随处书写"的理念，同一套代码可以同时覆盖 Android、iOS 等多个平台。它由 Meta 与全球众多公司和核心贡献者共同维护，是目前最主流的跨端开发方案之一。

## ✨ 主要特性

- **原生 UI**：基础组件直接渲染为各平台的原生界面控件，手势、文字缩放和无障碍表现与原生应用完全一致。
- **处处皆 React**：声明式 UI、组件、Hooks 与 Suspense 可在 Android、iOS 及其他平台之间复用。
- **开发速度快**：JavaScript 改动通过 Fast Refresh 秒级热更新生效，无需重新编译原生应用。
- **自由扩展**：Native Modules 让你从 JavaScript 同步、类型安全地调用平台原生代码，也可直接使用社区数千个现成库。
- **框架生态成熟**：官方推荐通过 Expo 等框架起步，内置文件路由与原生模块标准库，开箱即用。
- **渐进式接入**：既可全新建项目，也能嵌入现有原生应用逐步迁移。
- **开放治理**：由 React 基金会支持，提案与版本发布均在公开的社区仓库中讨论。

## 🚀 快速开始

1. 按照[环境搭建指南](https://reactnative.dev/docs/environment-setup)配置开发环境；已有原生应用可参考[与现有应用集成](https://reactnative.dev/docs/integration-with-existing-apps)渐进式引入。
2. 官方推荐使用框架创建项目（以 Expo 为例），在终端运行：

```bash
npx create-expo-app@latest
```

3. 跟随 [Expo 入门指南](https://docs.expo.dev/get-started/set-up-your-environment/)完成剩余配置并启动开发。
4. 若不使用框架，请参考[不使用框架的入门文档](https://reactnative.dev/docs/getting-started-without-a-framework)，自行处理导航、原生依赖与平台工具链。
5. 前往[官网文档](https://reactnative.dev/docs/getting-started)系统学习：入门教程、组件与 API、原生模块、调试、升级与架构一应俱全。
